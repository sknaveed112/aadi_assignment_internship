# TaskFlow – ReactJS Development Assignment

A responsive task-management dashboard built with React and Vite.

## Features
- React functional components
- useState for task/filter/theme state
- useMemo for filtered task rendering
- Add, search and filter tasks
- Click task status to cycle Pending → In Progress → Completed
- Light/Dark mode
- Responsive desktop and mobile UI
- No backend required

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.
